# 詐欺を切れ！- 百人一首風詐欺電話判定ゲーム

## 🎮 ゲーム概要

「詐欺を切れ！」は、特殊詐欺防止啓発を目的とした、スマートフォン向けのブラウザゲームです。

電話の内容を2行で提示され、詐欺電話か普通の電話かを素早く判断し、「受ける」か「切る」を選択します。

### 🎯 ゲームの狙い

- 詐欺電話の"決定的なワード"を学習
- 瞬間判断力を鍛える
- 特殊詐欺被害の予防啓発

## 🚀 実行方法

### 前提条件

- モダンブラウザ（Chrome、Firefox、Safari、Edge等）
- インターネット接続（不要 - ローカルで動作可能）

### セットアップ

#### 方法1: ローカルサーバー（推奨）

```bash
# プロジェクトディレクトリに移動
cd e:\self_game\sagi_game

# Pythonサーバーを起動（Python 3.x）
python -m http.server 8080

# または Python 2.x の場合
python -m SimpleHTTPServer 8080
```

その後、ブラウザで以下にアクセス：
```
http://localhost:8080
```

#### 方法2: Node.js (npx)

```bash
# npx を使用（Node.js インストール必須）
npx http-server -p 8080
```

#### 方法3: 直接ファイルを開く

`index.html` をダブルクリックしてブラウザで開く
（ただしCSVの読み込みが動作しない場合があります）

## 🎮 ゲーム内容

### 画面構成

1. **タイトル画面**
   - ゲーム説明
   - スタートボタン

2. **ゲーム画面**
   - 上部：スコア、通話番号カウント、コンボ表示
   - 中央：1行目と2行目の電話台詞
   - 危険度メーター：危険ワードに反応して警戒度を表示
   - 下部：「受ける」「切る」ボタン
   - 回答後：危険ワードと判断理由のミニ解説

3. **結果画面**
   - 最終スコア
   - ランク表示（S/A/B/C/D）と称号
   - 正答率
   - 最大コンボ
   - 啓発メッセージ
   - リスタートボタン

### ゲームフロー

1. 1行目の台詞が表示される（例：「警察の者ですが。」）
2. 0.7秒後、2行目が表示される（例：「暗証番号を教えてください。」）
3. プレイヤーが「受ける」または「切る」を選択
4. 正誤判定とスコア加算
5. 15通話終了後、結果画面へ

問題はゲーム開始時にシャッフルされ、同じプレイ中は同じ問題が重複して出題されません。

回答後には、危険ワードと判断理由が短く表示されます。連続正解するとコンボが伸び、結果画面ではランクに応じた称号も表示されます。

### スコアリング

難易度によって詐欺電話の割合、反応時間の基準、得点、ランク判定が変わります。

#### 詐欺電話（category=fraud）を正しく「切る」場合

| 難易度 | 詐欺割合 | Fast | Medium | Normal | Slow | 誤答 |
|--------|---------|------|--------|--------|------|------|
| 簡単 | 70% | 2.4秒以内 +8 | 3.0秒以内 +6 | 3.8秒以内 +3 | 3.8秒超 +1 | -8 |
| 通常 | 62.5% | 1.6秒以内 +10 | 2.2秒以内 +7 | 3.0秒以内 +4 | 3.0秒超 +1 | -10 |
| 難題 | 50% | 1.2秒以内 +12 | 1.8秒以内 +9 | 2.4秒以内 +6 | 2.4秒超 +2 | -12 |

#### 普通の電話（category=normal）を正しく「受ける」場合

| 難易度 | Fast | Medium | Normal | Slow | 誤答 |
|--------|------|--------|--------|------|------|
| 簡単 | 2.6秒以内 +5 | 3.3秒以内 +3 | 4.3秒以内 +2 | 4.3秒超 +1 | -2 |
| 通常 | 1.8秒以内 +6 | 2.5秒以内 +4 | 3.5秒以内 +2 | 3.5秒超 +1 | -3 |
| 難題 | 1.4秒以内 +8 | 2.0秒以内 +6 | 2.8秒以内 +3 | 2.8秒超 +1 | -5 |

#### その他（category=other）
- **0点**（スコア変動なし、演出用）

### ランク判定

| 難易度 | S | A | B | C | D |
|--------|---|---|---|---|---|
| 簡単 | 80点以上 | 60点以上 | 40点以上 | 20点以上 | 20点未満 |
| 通常 | 120点以上 | 90点以上 | 60点以上 | 30点以上 | 30点未満 |
| 難題 | 180点以上 | 140点以上 | 100点以上 | 60点以上 | 60点未満 |

## 🔊 効果音ファイル

ゲームを完全に楽しむために、以下の効果音ファイルを `sagi_game` フォルダに配置してください：

| ファイル名 | タイミング | 説明 |
|-----------|----------|------|
| `call.mp3` | 出題時 | 電話が鳴る音 |
| `correct_answer.mp3` | 正解時 | 正解の音 |
| `wrong_answer.mp3` | 誤答時 | 誤答の音 |
| `ending.mp3` | 結果発表時 | ゲーム終了の音 |

### 効果音ファイルの準備方法

**方法1: オンラインで効果音をダウンロード**
- フリー効果音サイト（Freesound.org, Zapsplat など）から MP3 形式で取得

**方法2: 音声編集ソフトで作成**
- Audacity（フリー）などで効果音を生成・編集

**方法3: ファイルなしで実行**
- 効果音がない場合、ゲームは正常に動作します（音声なし）

## 📊 データ形式（CSV）

### ファイル：`data.csv`

```csv
id,category,line1,line2,correct_action
1,fraud,"もしもし、検察庁ですが。","お客さんの口座の残高を確認させていただきたいのですが。",cut
...
```

### カラム説明

| カラム | 説明 | 例 |
|--------|------|-----|
| id | 通し番号 | 1, 2, 3... |
| category | 電話の種類 | fraud / normal / other |
| line1 | 1行目（導入） | "警察の者ですが。" |
| line2 | 2行目（本題） | "暗証番号を教えてください。" |
| correct_action | 正解 | cut / accept / either |

### category の種類

- **fraud**: 詐欺電話 → 正解は「切る」
- **normal**: 普通の電話 → 正解は「受ける」
- **other**: その他 → 「受ける」「切る」のどちらでも可

## 🛠️ カスタマイズ

### 問題を追加

`data.csv` に新しい行を追加：

```csv
21,fraud,"厚生年金からです。","還付金のお手続きをさせます。口座番号をお教えください。",cut
```

### 問題を削除

該当行を削除するだけです。

### 難易度・総通話数を変更

`script.js` の `difficultySettings` を編集します。

```javascript
const difficultySettings = {
    normal: {
        totalCalls: 15,      // 総通話数
        fraudRatio: 0.625    // 詐欺電話の割合
    }
};
```

### スコアリングを調整

`script.js` の `difficultySettings` 内にある `scoringRules` を編集します。

```javascript
difficultySettings.normal.scoringRules.fraud.correct.fast = {
    threshold: 1.6,  // 秒数の基準
    points: 10      // 得点
};
```

## 🐛 トラブルシューティング

### ゲームが起動しない

1. ブラウザのコンソールを確認（F12キー）
2. エラーメッセージをチェック
3. ファイルパスが正しいか確認

### CSVが読み込めない

- CORS エラーが発生している場合は、ローカルサーバーで実行してください
- ファイルが UTF-8 で保存されているか確認
- ファイル名が `data.csv` か確認

### スマートフォンで表示がおかしい

- ブラウザのズームをリセット（100%に設定）
- 画面を回転させない（縦画面推奨）
- キャッシュをクリアして再読み込み
